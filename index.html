Restomatic

A desktop GUI client for REST APIs

Download JAR Download for macOS (Apple Silicon)

Runs on Windows, Linux, macOS. Requires Java 21 or later.

Features

Request templates

  • Define path and query parameters.
  • Define request headers.
  • Supports various request body types: text, form, multipart, and file.
  • Dynamically organise the request hierarchy as the request path changes.
  • Search across requests.
  • Use temporary request templates to experiment without modifying the original template.
  • View JSON responses as a tree.

Targets

  • Define headers to apply to every request sent to a target.
  • Assign colours to visually distinguish each target.
  • Override headers for specific context paths within a target.
  • View and modify cookies received during request execution.

Authenticators

  • HTTP Basic authentication.
  • Custom authentication scenarios using JavaScript.

Profiles

  • Store environment-specific data in profile variables.
  • Enable multiple profiles (e.g., "User Joe" and "Target dev2").
  • Substitute profile variables using Handlebars expressions.

FAQ

Which download do I need?

The macOS download is an Apple Silicon dmg that bundles Java. Intel Macs, Windows and Linux use the JAR, which needs Java 21+ (download a JRE).

After installing Java, run:

java -jar restomatic.jar

How do I run the macOS app on Apple Silicon?

Requires an Apple Silicon Mac running macOS 15 (Sequoia) or later. Java is bundled, so no separate Java install is needed.

Open the downloaded dmg and drag Restomatic into Applications.

The first launch is blocked because the app is unsigned and not notarised.

This is expected, and macOS gives you a way through:

  1. Double-click Restomatic, then click Done — not Move to Trash.
  2. Open System Settings → Privacy & Security, scroll to Security, and click Open Anyway.
  3. Authenticate, then open the app.

The Open Anyway button appears for about an hour after the blocked attempt. If it is missing, double-click the app again and return.

Later launches work normally.

If it still won't open, remove the quarantine flag in Terminal:

xattr -dr com.apple.quarantine /Applications/Restomatic.app

How is Restomatic different from Postman or Insomnia?

A workspace is a plain JSON file you can commit or hand to a colleague, with no account or cloud service. Endpoints carry their own contexts, headers, cookies and authenticators, and profiles switch environments. The client is a desktop app, not a browser runtime.

Where are my workspaces stored?

A workspace is a JSON file saved wherever you choose. Keep it in version control or send it to a colleague; Restomatic does not keep a copy on a server.

Does Restomatic work offline?

Yes. Workspaces and settings live on your disk. Apart from the optional update check, Restomatic only uses the network when you send a request.

Does Restomatic collect any user data?

No. There is no account, no telemetry and no cloud service, and workspaces stay on your disk. The only automatic network call is a check for the latest release on GitHub, which sends no workspace data.

You can turn the update check off in the Restomatic application menu on macOS, or under Workspace → Settings on Windows and Linux.

Is there an example workspace file?

Check the GitHub example workspace. It showcases a subset of the GitHub REST API. After opening the workspace file, change the values of the "token" and "userId" parameters inside the "auth info" profile.
